Project Brief: Full Landing Page Redesign (v8)
Project Overview: We are completely redesigning the client/src/pages/landing.tsx file. The current page is a simple placeholder. The new page will be a comprehensive, multi-section marketing page that fully explains our product, builds desire, and drives users to sign up for their 3 free credits.

Core Goal: Transform the landing page into a "magical" and "friendly" experience for parents. It must be beautiful, trustworthy, and clearly communicate the value of our personalized audio stories. It must be SEO-friendly and fully responsive.

Key Design Principles (from design_guidelines.md):

Fonts: All headings, subheadings, and buttons must use font-display (Quicksand). Body/paragraph text will use font-sans (Inter).

Theme: The page must use the new "cozy" theme: a warm, "parchment" (off-white) background for light mode and a "night sky" indigo for dark mode.

Feel: All components must be "softened" using larger border radii (rounded-xl or rounded-2xl) on Card and Button components.

Translation: All text MUST be pulled from the translation files using the useTranslation() hook.
